# nabs-birthday

This repository contains a single-page birthday card built as a static HTML experience.

Files in the repo:
- `Berries and Cream.html` — the interactive birthday page with text, animations, and embedded styling/scripts.
- `song.mp3` — the background music track used by the page.
- `.gitattributes` — repository metadata for Git LFS/line-ending handling.

How to view it:
1. Open `Berries and Cream.html` in a browser.
2. If the music does not play immediately, serve the folder locally (for example with `python -m http.server`) and open the page from that local server.

This is a lightweight static website, not a framework or app with separate source/build folders.
